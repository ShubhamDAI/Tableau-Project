## Project Overview
Analyzed Daikibo's machine telemetry data for May 2021 using Tableau to identify factory downtime and machine performance.

## Key Tasks
- Imported and analyzed JSON telemetry data.
- Created a calculated field named **Unhealthy**, assigning 10 minutes of potential downtime to each unhealthy status.
- Built a bar chart to visualize downtime by factory.
- Created a second bar chart to analyze downtime by device type.
- Developed an interactive dashboard with factory-level filtering.
- Identified the factory with the highest downtime and analyzed its most problematic device types.

## Tools Used
- Tableau
- JSON Data
- Calculated Fields
- Data Visualization
- Interactive Dashboards

## Objective
To identify which factory experienced the most downtime and determine which types of machines broke most frequently, helping support data-driven maintenance decisions.
